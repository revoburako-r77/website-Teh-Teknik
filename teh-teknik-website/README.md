# Teh Teknik — Landing Page

Landing page responsif untuk brand UMKM Teh Teknik, dibuat dengan HTML, Tailwind CSS CDN, dan JavaScript vanilla.

## Menjalankan di VS Code
1. Ekstrak folder proyek.
2. Buka folder `teh-teknik-website` di Visual Studio Code.
3. Buka `index.html` langsung di browser, atau gunakan ekstensi **Live Server** lalu pilih **Open with Live Server**.
4. Koneksi internet dibutuhkan untuk memuat Tailwind CSS, Google Fonts, dan peta Google Maps.

## Struktur
- `index.html` — seluruh layout, styling, navigasi, dan interaksi.
- `assets/es-teh.jpg` — foto produk.
- `assets/logo-bulat.jpg` — logo bulat.
- `assets/logo-teks.jpg` — logo alternatif.
- `assets/booth.jpg` — foto booth.

## Catatan
- Tidak ada ikon atau tautan Instagram, Facebook, maupun WhatsApp.
- Form kontak saat ini berupa demo frontend: memvalidasi input dan menampilkan konfirmasi di halaman, tetapi belum mengirim data ke server.
- Peta memakai sematan Google Maps untuk area Fakultas Teknik Unsoed; pastikan titik booth aktual sebelum dipublikasikan.
